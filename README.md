# 四种社会形态 · 互动学习页

面向中学政治课：原始社会的解体和阶级社会的演进 + 四种社会形态比较。

## 如何打开

### 方法一：直接打开文件

用浏览器打开本目录下的 `index.html` 即可（离线可用，无需联网）。

### 方法二：本地静态服务器

在本目录执行：

```bash
python3 -m http.server 8765
```

然后在浏览器访问：http://127.0.0.1:8765/

## 功能

1. **时间线**：点选四个社会阶段，查看要点与演进原因  
2. **对比表**：点击单元格高亮同行/同列，并弹出解说  
3. **配对游戏**：社会形态与生产工具、所有制、主要矛盾配对，计分可再玩  
4. **小测验**：12 道单选题，即时反馈与成绩庆祝  
5. **总览图**：简化思维导图，一眼看清演进  

首次打开会显示「怎么玩」说明（可用浏览器本地存储记住已读）。
