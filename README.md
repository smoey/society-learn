# 四种社会形态 · 互动学习页

面向中学政治课：原始社会的解体和阶级社会的演进 + 四种社会形态比较。

## 如何打开

### 方法一：直接打开文件

用浏览器打开本目录下的 `index.html` 即可（离线可用，无需联网）。

### 方法二：本地静态服务器

在本目录执行：

```bash
python3 -m http.server 8765
```

然后在浏览器访问：http://127.0.0.1:8765/

## 功能

1. **时间线**：一次看一个阶段故事卡（场景图 + 记忆口诀 + 要点）；左右滑动或点「上一/下一阶段」；进度条可跳转  
2. **对比表**：按维度芯片浏览四种社会卡片（无横向整表滚动）；点卡片看解说；可选展开完整表  
3. **配对游戏**：社会形态与生产工具、所有制、主要矛盾配对，计分可再玩；工具轮可视化图标  
4. **小测验**：12 道单选题，即时反馈与成绩庆祝  
5. **总览图**：简化思维导图，一眼看清演进；各阶段卡片含场景缩略图  

## 插图

`images/` 目录含四种社会场景图（16:9）与四种生产工具图标（1:1），帮助用视觉线索记忆概念。相对路径引用，可在 GitHub Pages 直接访问。

首次打开会显示「怎么玩」说明（可用浏览器本地存储记住已读）。
